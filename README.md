## 📌 Описание проекта

Чат-бот реализует **диалоговый интерфейс для навигации по семантическому графу** знаний, охватывающему ключевые события, личности и институты Европы рубежа XVIII–XIX веков.

Пользователь задаёт вопросы на естественном языке — бот выполняет алгоритмы обхода графа (BFS, DFS, Dijkstra) и возвращает результат с объяснением от локальной языковой модели.

```
Пользователь: «найди путь от ФР до ВКО»
        │
        ▼
  Граф-движок (BFS)          NLP-обработка запроса
  ФР → НАП → ИМП → ВКО       Определение узлов + алгоритма
        │
        ▼
  Ollama LLM (локально)
  «Путь отражает логику эпохи: Французская революция
   выдвинула Наполеона, он основал Империю, крушение
   которой привело к Венскому конгрессу...»
```

## 🏗️ Архитектура

```
semantic_graph_chatbot/
│
├── main.py            ← Точка входа, CLI-интерфейс
├── chatbot.py         ← Логика бота, интеграция с Ollama, системные промпты
├── graph_engine.py    ← Алгоритмы BFS / DFS / Dijkstra
├── graph_data.py      ← Данные графа: узлы и рёбра
└── requirements.txt   ← Зависимости (только requests)
```

**Поток данных:**

```
Ввод пользователя
      │
      ▼
  chatbot.py
  ├─ _parse_intent()    → определить тип запроса
  ├─ _extract_nodes()   → найти узлы в тексте
  │
  ├─ graph_engine.py
  │   ├─ bfs_path()     → кратчайший путь (по рёбрам)
  │   ├─ dfs_path()     → путь в глубину
  │   ├─ dijkstra_path()→ кратчайший путь (по весам)
  │   └─ get_neighbors()→ соседние узлы
  │
  └─ Ollama API (localhost:11434)
      └─ LLM интерпретирует и объясняет результат
```

## 🚀 Быстрый старт

### 1. Клонировать репозиторий

```bash
git clone https://github.com/<ваш-логин>/semantic-graph-chatbot.git
cd semantic-graph-chatbot
```

### 2. Установить зависимости Python

```bash
pip install -r requirements.txt
```

> Требуется Python 3.10+. Сторонних библиотек нет — только стандартный `requests`.

### 3. Установить Ollama

Скачать с официального сайта: **https://ollama.com**

| Платформа | Способ установки                          |
|:----------|:------------------------------------------|
| Windows   | Скачать `.exe`-installer с ollama.com     |
| macOS     | `brew install ollama`                     |
| Linux     | `curl -fsSL https://ollama.com/install.sh \| sh` |

### 4. Запустить Ollama и загрузить модель

```bash
# Запустить сервер Ollama (в отдельном терминале или как фоновый процесс)
ollama serve

# Загрузить модель (выбрать одну, ~2–8 ГБ)
ollama pull llama3.2       # Рекомендуется: 2 ГБ, быстрая
ollama pull mistral        # Хороший баланс: 4 ГБ
ollama pull gemma2:9b      # Качественная: 5.5 ГБ
ollama pull phi3:mini      # Лёгкая: 2.3 ГБ
```

> ⚠️ Модели размером более 32B не рекомендуются — долгое время ответа на обычных компьютерах.

### 5. Запустить чат-бота

```bash
# С моделью по умолчанию (llama3.2)
python main.py

# С конкретной моделью
python main.py mistral
python main.py gemma2:9b
```

## 🗺️ Семантический граф

Граф описывает **Европу на переломе эпох (1789–1815)**: от Французской революции до Венского конгресса.

### Узлы по категориям

| Категория    | Узлы                                                                                 |
|:-------------|:-------------------------------------------------------------------------------------|
| Событие      | ФР, 18Б, КОА, ОВ12, МОС, ВКО, ТИЛ, КОН_Б, ИСП, СТО, БАС                           |
| Сражение     | АУС, БОР, ВАТ, ТРА, ЕНА                                                             |
| Личность     | НАП, АЛ1, КУТ, НЕЙ, БЛЮ, ВЕЛ                                                        |
| Институт     | КОН, ИМП, СВЯ, КОД, ДЕК                                                             |
| Место        | ЭЛЬ                                                                                  |
| Алгоритм     | BFS, DFS, DIJ                                                                        |

### Пример причинно-следственных цепочек

```
ФР ──выдвинула──▶ НАП ──совершил──▶ 18Б ──учредил──▶ КОН ──предшествовало──▶ ИМП
                   │                                                              │
                   └──победил_при──▶ АУС ──предшествовал──▶ ТИЛ               основал
                                                               │
                                                           расширил
                                                               │
                                                           КОН_Б ◀──нарушение──▶ ОВ12
```

Рёбра имеют **веса от 1 до 5** (1 = прямая, сильная связь; 5 = косвенная, слабая).  
Алгоритм Дейкстры находит «семантически наиболее тесно связный» путь между узлами.

## ⚙️ Алгоритмы навигации

### BFS — Поиск в ширину

```
Запрос: путь от ФР до ВКО

Уровень 0: [ФР]
Уровень 1: [НАП, КОА, БАС, ДЕК, 18Б]
Уровень 2: [КОН, ИМП, АУС, ОВ12, ...]
Уровень 3: [ВКО] ← найден!

Гарантия: минимальное число рёбер
```

### DFS — Поиск в глубину

```
Запрос: путь от ФР до ВКО

ФР → НАП → 18Б → КОН → ИМП → ... → ВКО

Результат: может быть длиннее BFS
Особенность: нет гарантии оптимальности
```

### Dijkstra — Кратчайший взвешенный путь

```
Запрос: путь от ФР до ВКО

Минимизируется суммарный вес рёбер.
Гарантия: наиболее «тесно связанная» цепочка событий
```

### Сравнение алгоритмов

| Характеристика         | BFS                  | DFS                      | Dijkstra                 |
|:-----------------------|:---------------------|:-------------------------|:-------------------------|
| Гарантия оптимальности | По числу шагов       | Нет                      | По сумме весов           |
| Использование памяти   | O(V)                 | O(глубина)               | O(V log V)               |
| Скорость               | Умеренная            | Быстрый старт            | Медленнее на больших     |
| Когда использовать     | Кратчайшая цепочка   | Проверка связности       | Взвешенный кратчайший    |

## 🔧 Настройка модели и промптов

### Смена модели

В файле `chatbot.py`, строка:
```python
OLLAMA_MODEL = "llama3.2"   # Изменить на: mistral, gemma2:9b, phi3:mini, qwen2.5
```

Или через аргумент командной строки:
```bash
python main.py mistral
```

### Настройка параметров LLM

В файле `chatbot.py`, блок `options`:

```python
"options": {
    "temperature": 0.3,    # 0.0 = детерминированный, 1.0 = творческий
    "top_p": 0.9,          # Nucleus sampling
    "num_ctx": 4096,       # Размер контекстного окна
    "repeat_penalty": 1.1  # Штраф за повторения
}
```

### Изменение системного промпта

Переменная `SYSTEM_PROMPT` в `chatbot.py` определяет роль и поведение LLM.  
Для адаптации под другую тематику — обновить описание узлов в промпте и данные в `graph_data.py`.
